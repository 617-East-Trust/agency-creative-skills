# Implementation handoffs — agency execution depth

Use after the shared engagement brief establishes a real build or launch. These are **handoff contracts**, not a replacement for a dedicated design, motion, or measurement specialist.

## Brand positioning

Deliver: audience, differentiated promise, proof hierarchy, message hierarchy, and claims that need evidence. Connect each promise to a visible page section and conversion action.

## Design system

Deliver: type scale, color roles, spacing scale, grid/breakpoints, component states, responsive behavior, focus/contrast rules, and asset usage. Explain any familiar visual choice by its role in the brief; reject unjustified sameness, not specific fonts, gradients, or card layouts by default.

## Motion / 3D engineering

Deliver: interaction specification, asset budget, loading sequence, mobile degradation, `prefers-reduced-motion` behavior, failure fallback, and measurable LCP/INP/CLS guardrails. Technical Website Soundness owns production performance evidence.

## Conversion measurement

Deliver: event taxonomy, primary conversion definition, form/CRM route, consent/attribution assumptions, test plan, and verified lead-path check. Do not call a conversion event implemented until the runtime evidence exists.

## Handoff minimum

In the full pack, validate against the shared artifact schema. In a standalone install, still carry brief ID, inputs, finding IDs, limitations, requested output, owner, and completion criteria. Route client-facing narration to Premium Report Craft.
