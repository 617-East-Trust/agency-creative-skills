# Creative review rubric — brand / UX / visual evidence

Use for Agency Creative Studio `review-existing` mode. Prefer live URL fetch, screenshots, or user-supplied brand packs. Separate **observed** facts from **judgment**.

## Inputs
- Primary URL(s) and key templates (home, money page, pricing, contact)
- Brand assets (logo, type, color, voice guidelines) if any
- Competitors (optional)
- Review goal (teardown, redesign brief, competitive, pre-rebrand)

## Qualitative scale
Use **strong / uneven / weak / not evaluated (N/E)** — not a false-precision 1–5 when judgment dominates.

## Passes

### A. Brand
- Distinctive point of view vs category sameness
- Consistency of voice, logo lockups, color, imagery
- Promise clarity: what you do, for whom, why it matters

### B. IA / UX
- Findability of primary tasks; nav clarity; cognitive load
- Form friction; error states; mobile usability
- Journey continuity (ad/email → landing message match)

### C. Visual craft
- Hierarchy in a 3-second skim; typography pairing; spacing rhythm
- Avoidance of generic AI UI (Inter-only, purple gradients, identical card grids)
- Photography/illustration quality and crop discipline

### D. Motion / immersive
- Motion serves hierarchy (not decoration spam)
- `prefers-reduced-motion`; performance cost of scroll/3D
- Mobile fallbacks for WebGL/heavy sequences

### E. Copy / CRO
- Above-fold clarity: what / who / outcome / primary CTA
- Proof near claims; objection handling
- One primary CTA; label specificity (`[verb] + [outcome]`)

### F. Competitive (if comps)
- Relative positioning; stolen opportunities; table-stakes gaps

## Evidence log format

| ID | Pass | Observation (URL/screenshot/quote) | Judgment | Severity (impact × effort) |
| --- | --- | --- | --- | --- |
| R-01 | Visual | Hero uses three competing CTAs equal weight | Weak conversion hierarchy | High impact / Low effort |

## Output package
1. Snapshot (3–5 sentences)
2. Scorecard per pass (strong / uneven / weak / N/E)
3. Top 5 fixes sorted by impact × effort
4. Evidence log
5. Redesign brief (direction seeds for next engagement)
6. Handoffs (copy, design, growth reference, Technical Website Soundness, Premium Report Craft)

## Honesty rules
- No invented analytics or competitor traffic numbers
- If you could not load the URL, say so and review from supplied assets only
- Growth-only ranking questions: prefer growth-routing or technical skill unless a broad redesign is requested
