# Deck narrative — slide story when slides tooling is limited

Use when the user needs a live presentation narrative and dedicated Slides MCP/tooling is **not** available. If slides tooling **is** present, hand the shaped narrative to that workflow for actual PPT/PPTX generation — do not invent a parallel deck format as a hard dependency.

## Principles
- One primary decision-relevant takeaway per slide  
- ≤3 evidence points per slide  
- Titles are sentences with verbs, not topic labels  
- Speaker notes are mouth-ready (spoken rhythm)  
- Appendix slides hold method and overflow evidence  

## Story shapes

| Goal | Beat sequence |
| --- | --- |
| Decision | Context → stakes → options → recommendation → ask |
| Findings | Question → method snapshot → 3 findings → implication → next step |
| Board | Outcomes vs plan → drivers → risks → decisions needed |
| Pitch | Problem → stakes → solution → proof → offer |

## Slide checklist
- [ ] Can the slide be understood in 5 seconds without the speaker?  
- [ ] Does every chart earn its place?  
- [ ] Is the ask on its own slide near the end?  
- [ ] Are hypotheses labeled?  
- [ ] Hybrid pack: deck for decision, report appendix for ledger/detail  

## Delivery without Slides MCP
Ship: Markdown slide outline (`## Slide N — Takeaway`) + speaker notes + optional simple HTML review deck. State clearly that a native PPTX was not generated if tooling was absent.
